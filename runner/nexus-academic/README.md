# NEXUS — Pembantu akademik

Mandat: pembangunan kemampuan akademik, bukan pemburuan pendapatan. 12 modul, satu sesi harian pada 09:23 MYT (jadual GitHub mungkin lewat). Kurikulum, contoh latihan asal dan alat audit boleh digunakan semula. Rekod kemajuan disimpan dalam `progress.json`. Status latihan bukan bukti penguasaan bebas atau perubahan berat model. Audit BM ialah cadangan kontekstual, bukan hakim tatabahasa. Sumber awam diperiksa untuk capaian; DOI disemak pada Crossref apabila relevan. Jangan muat naik manuskrip PhD, nota penyelia, data peserta, data pelajar atau sumber berhak cipta ke repositori awam. Untuk manuskrip sebenar gunakan ruang kerja peribadi dan polisi institusi. Gaya UKM ialah rujukan permulaan, bukan andaian institusi pendaftaran. Tiada penghantaran jurnal, permohonan atau bayaran automatik. Fail pemburu lama dikekalkan sebagai sejarah, tetapi aliran kerja yang sama kini hanya menjalankan latihan akademik.
