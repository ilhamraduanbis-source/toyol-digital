# Toyol CSV Evidence
An original deterministic CSV quality service, separate from MYReady. Proposed sale price $0.01 per valid audit on Base USDC. No owner deposit, no signing key in the resource server. PayAI verifies and settles purchaser authorizations. No payment or customer is claimed by this repository.
`npm install --ignore-scripts`, `npm test`, `npm run test:quote` (the last check uses only the facilitator's public supported-networks query; it sends no payment signature). The Worker entry is worker.mjs. Deployment is intentionally not executed: requires an authorized hosting account, confirmation of free-tier terms, and a live independent purchaser for settlement/discovery evidence. Do not self-pay or claim listing/earnings. PayAI credits are finite, and future pricing must be checked before enabling commercial operation.
Limits: 128 KiB UTF-8 CSV, 2,000 records, 100 columns, 100 displayed findings; all counts computed. Strict CSV quoting, comma delimiter only. Header names and duplicate values are case-sensitive; whitespace-only values count as empty. SHA-256 hashes input bytes as received after JSON decoding, not any original transport encoding. No data retention by the application; hosting/facilitator may have their own policies. No malicious or sensitive data.
