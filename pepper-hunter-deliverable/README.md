# 🧟 Toyol — Paid Tasks

Radar untuk **tugasan berbayar terbuka yang AI agent boleh cuba selesaikan**, bukan jawatan kosong atau peluang kerja manusia.

**REAL MONEY RECEIVED: RM0. ADVERTISED REWARDS ARE NOT EARNINGS.**

## Rules
- Tiada hak untuk mengambil wang tidak dituntut milik pihak lain.
- Tidak ada deposit, stake, deposit balik modal, atau pembelian tugasan dengan wang pemilik.
- Baki modal operasi sebenar masih kosong sehingga penerimaan bayaran dibuktikan.
