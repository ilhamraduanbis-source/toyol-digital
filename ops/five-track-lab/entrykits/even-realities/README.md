# Even Hub G2 - AI Assistants & Work

Functional TypeScript SDK integration and local simulator scripts are in the existing full Toyol Five Track Lab ZIP, integrations/even-g2/. GitHub CI already compiles the SDK source. Static cards are not a complete AI assistant and do not meet the full judging intent.

Original product direction: a hands-free work-decision HUD showing evidence provenance, action status, and next permissible action with one-click navigation. No crypto payments or user credentials.

To pursue a genuine event entry at zero purchase cost: npm install, npm run dev, npm run sim, capture REAL simulator footage <=3 minutes, publish README/source, register with event platform and submit. Simulator success and official registration remain unverified. Review DoraHacks' broad license before submission.
