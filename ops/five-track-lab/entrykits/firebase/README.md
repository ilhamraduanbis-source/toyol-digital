# Firebase Hybrid AI - Safe demonstration gate

Existing independent original code in full lab ZIP integrations/firebase-hybrid/ builds with Firebase AI Logic SDK and uses InferenceMode.ONLY_ON_DEVICE unless cloud use and free quota are explicitly confirmed. This avoids cloud spending but does not prove full hybrid functionality or a contest entry.

Required actual work: create a real Firebase project without billing, use a compatible desktop Chrome, initialize an actual local model through Firebase AI Logic, document on-device response, and only test cloud fallback if no-cost quota and spend protection have been verified. Capture a demonstrative video, public source, and then submit on Devpost. No API keys, billing or network inference has been executed by this readiness kit.
