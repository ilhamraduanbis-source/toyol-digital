# Design notes

The tool parses ATX headings and common single-line Setext headings, ignores fenced code, and removes inline links, code delimiters, and paired emphasis while preserving their visible text. Unicode letters, combining marks and numbers remain in lowercase slugs; punctuation is stripped except hyphens and underscores. Spaces become hyphens. Duplicate slugs are numbered and checked against all previous IDs, including headings that already contain numeric suffixes. Indentation is based on heading level rather than the preceding heading, so skipped levels are safe. The CLI uses only Python's standard library and reports unreadable or invalid UTF-8 files on stderr. It is a deliberately bounded Markdown parser, not a full CommonMark/GFM implementation: complex multiline headings, raw HTML blocks, unusual reference links, and GitHub's complete Unicode slugger table can differ.
